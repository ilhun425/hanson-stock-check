# 재고 확인

(주)핸썬 기술영업팀용 웹앱입니다. 하드웨어 스펙북 엑셀과 이카운트 재고현황 엑셀을 넣으면, 스펙 품목마다 재고 충분 / 일부 부족 / 확인 필요 / 발주 필요를 판정합니다.

- 넣은 엑셀은 휴대폰·PC 브라우저 안에서만 읽습니다. 서버로 보내지 않습니다.
- 가용 수량 = 반입재 + 상용재고 (반재는 보수용 참고)
- 읽을 수 있는 스펙북: 엄지하우스(4-0.door list), 두양건축(수량 시트), 서울파이낸스센터(ITEM LIST), 그 밖에 모델·수량 열이 있는 목록
- 회사 PC 프로그램이 평일 매시간 재고현황을 암호로 잠가 `data/stock.json`에 올리고, 앱은 암호를 한 번 넣으면 최신 재고를 자동으로 불러옵니다. 암호 없이는 내용을 볼 수 없습니다.
- 휴대폰에서 주소를 연 뒤 "홈 화면에 추가"하면 앱처럼 쓸 수 있고, 한 번 연 뒤에는 인터넷 없이도 열립니다.

파일을 고친 뒤에는 `sw.js`의 `VERSION` 값을 바꿔야 휴대폰에 새 버전이 반영됩니다.
